# 🌕 MoonAnything  
**A Vision Benchmark with Large-Scale Lunar Supervised Data**
Accepted at ACM MMsys 2026

MoonAnything is a large-scale supervised vision benchmark designed for computer vision research on lunar imagery.  
It provides diverse annotated lunar data to support tasks such as detection, segmentation, recognition, and geometry-aware learning.

---

## Dataset Access

The dataset is hosted on **Zenodo**.

 **[Access the dataset on Zenodo](https://zenodo.org/records/18415119)**

##  Important Note (Sample Release)

The **full dataset will be released progressively** or via alternative hosting solutions.
